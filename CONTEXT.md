## Проект: SgrFLOW

Внутренний продукт для компании — **визуализация связей между людьми, проектами и продуктами** (knowledge graph, 3D-пузыри).

**Идея:** одна страница с 3D-графом, где узлы = люди / проекты / продукты, рёбра = связи (кто владеет чем, что зависит от чего). Размер пузыря = приоритет.

**Стек:** Vite + React + [3d-force-graph](https://github.com/vasturiano/3d-force-graph)

**Репозиторий:** https://github.com/Wintermuteuv/SgrFLOW (публичный)

**Статус:** прототип сделан (HTML/JS с демо-данными), следующий шаг — полноценное приложение с реальными данными.
