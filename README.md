# SgrFLOW

> Корпоративный knowledge graph — прозрачность приоритетов и связей между людьми, проектами и продуктами компании на одной странице.

![prototype screenshot](docs/preview.png)

## Идея

Одна проблема больших команд — никто не видит полной картины: кто что делает, какие проекты связаны, где узкие места. SgrFLOW делает эти связи видимыми.

**Три типа узлов:**
- 👤 **Люди** — сотрудники и отделы
- 🔧 **Проекты** — текущие инициативы
- 📦 **Продукты** — продукты и платформы компании

**Связи** показывают: кто владеет чем, что зависит от чего, кто работает на каком продукте.

**Размер пузыря** = приоритет узла. Чем важнее — тем крупнее.

## Демо

Открой [`prototype/index.html`](prototype/index.html) в браузере — работает без сервера, без установки зависимостей.

## Стек

| Слой | Технология |
|------|-----------|
| Визуализация | [3d-force-graph](https://github.com/vasturiano/3d-force-graph) (WebGL / Three.js) |
| UI | Vanilla JS, HTML, CSS |
| Данные (MVP) | JSON внутри HTML |
| Данные (roadmap) | REST API → Jira, GitLab, HR-система |
