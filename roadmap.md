## M1 — Living Prototype

**Цель:** заменить демо-данные реальными, задеплоить, показать руководству.

- [ ] Вынести данные в `data.json`
- [ ] Заполнить реальными людьми блока разработки Sergek
- [ ] Заполнить продуктами (VMS, Core, Patrol, ITS, Data, ECO, Platform)
- [ ] Заполнить активными проектами
- [ ] Расширить схему под новые типы узлов и связей (см. concept.md)
- [ ] Задеплоить на GitHub Pages
- [ ] Базовые фильтры по типу узла

**Результат:** живая карта блока разработки, доступная по ссылке.

-----

## M2 — HR Integration

**Цель:** люди подтягиваются из HR-системы автоматически, не вручную.

- [ ] Исследовать API / экспорт HR-системы
- [ ] Маппинг полей HR → схема SgrFLOW (company, role, department)
- [ ] Скрипт синхронизации HR → `data.json`
- [ ] Обработка увольнений / переводов (статус `inactive`)
- [ ] Оргструктура: выяснить ведёт ли HR `reportsTo`, иначе — ручной ввод

**Результат:** ~800 человек в графе без ручного ввода.

-----

## M3 — Rich Graph

**Цель:** читаемая визуализация для разных аудиторий.

- [ ] Переключатель POV (Продукт / Человек / Проект / Иерархия)
- [ ] Ego network — наведение гасит нерелевантные узлы
- [ ] Цвета и толщина рёбер по типу связи
- [ ] Тепловая карта нагрузки (зелёный → жёлтый → красный)
- [ ] Кластеризация: люди притягиваются к своему основному продукту/отделу
- [ ] Фильтры: по компании, департаменту, статусу проекта, типу связи
- [ ] POV Иерархия: org chart (дерево, не физика)

**Результат:** инструмент понятен без объяснений, каждый POV отвечает на конкретный управленческий вопрос.

-----

## M4 — Project Data

**Цель:** проекты и участники подтягиваются из Jira автоматически.

- [ ] Интеграция Jira REST API (jira.srgdev.kz)
- [ ] Маппинг: Jira project → SgrFLOW project node
- [ ] Маппинг: assignee/reporter → member_of / owns связи
- [ ] Статусы проектов из Jira (active/done/paused)
- [ ] Опционально: GitLab — репозитории как узлы или атрибуты продуктов

**Результат:** проектная часть графа обновляется автоматически.

-----

## M5 — Full Platform

**Цель:** инструмент для управленческих решений, не только визуализации.

- [ ] Временные снэпшоты — граф на любую дату
- [ ] Алерты перегрузки — уведомление когда load(person) > порога
- [ ] Ротационный анализ — кто может быть перемещён без критического риска
- [ ] Экспорт — скриншот / PDF для презентаций
- [ ] Ролевой доступ — каждый видит свой дефолтный POV
- [ ] Мобильная версия
