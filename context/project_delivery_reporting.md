Иван готовит сводную отчётность по направлению Delivery. Единый формат для нескольких команд блока разработки: VMS уже сделана, впереди ещё **3 команды** с несколькими досками Jira и git-репозиториями каждая.

**Why:** руководству нужна сопоставимая отчётность по всему блоку разработки — одинаковая структура у всех команд, чтобы быстро сравнивать прогресс и точки внимания.

**How to apply:** когда Иван даст ссылки на доски/репозитории следующих команд — переиспользовать executive-каркас (см. feedback_report_structure.md и reference_delivery_workspace.md), не изобретать новую структуру. Финальный отчёт по блоку = склейка одностраничек по командам в одинаковом формате.

**Состав отчётности по каждой команде:**
- Технический отчёт (детальный, .docx) — связка задач↔коммитов, метрики по типам/приоритетам/исполнителям, recommendations.
- Executive Summary (.docx, 1–2 страницы) — для руководителя.
- Markdown-версия — для внутреннего хранения.
- Сырые данные TSV — для аудита.
